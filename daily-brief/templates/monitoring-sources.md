# Source tiers — {CLIENT NAME}

Tier 5 = highest authority, 1 = include if little else, 0 = never include (counted, not shown).
Unlisted sources reach the reviewer flagged `tier ?` and get proposed for a tier after being
seen; signal-gather never invents a tier. Tier changes apply to future briefs only — shipped
briefs are immutable.

A web address in brackets after a source's name is what the Pulse report matches cited links
against. Add one when adding a source; a source with no address still gets its tier in the brief,
and shows as untiered in the Pulse report.
