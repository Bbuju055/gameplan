# Target list spreadsheet — template spec

Generated by export-list as CSV files, which Excel opens directly, in `<Client>/Pitch lists/`: the list `<Client> - <Release title> - <D Mon YYYY>.csv`, its
summary `… - summary.csv`, and, when needed, `… - for review.csv`.

## Summary file (always written; two columns: field, value)

| Field | Content |
|---|---|
| Client | display name |
| Release | title |
| Date finalized | date |
| Operator | name |
| List | id + version (small print; the one technical breadcrumb, for support) |
| Segments | one row per segment: name, count, rationale |
| Log snapshot | the parse-coverage line from the build ("read 412, used 407, skipped 5") |
| Footer | `org.confidential_footer` from config; omitted while TODO(org) |

## List file: every segment, each ranked by score

| Column | Rules |
|---|---|
| Segment | segment name; rows grouped by segment in the summary's order |
| Rank | 1..n within the segment |
| Deadline | deadline for reactive hits ("closes Sep 3"); reactive rows sort to the top |
| Reporter | from the frozen snapshot |
| Outlet | from the snapshot |
| Beat | from the snapshot |
| Score | 0–1, two decimals, tabular |
| Match reasons | plain English; discoveries/reactive include their citation links |
| Angle | the angle to lead with: the reporter's own from the angle notes for the top of each group, else the group's angle |
| Contact | email/phone from snapshot; discoveries without a publicly sourced email read "not found: verify manually"; publicly sourced ones still carry "verify contact before sending" |
| History flag | e.g. "on this client's Series A list saved 3 weeks ago"; a flag from another client's list keeps its wording with "another client" in place of the name — never stripped |
| Source | Log / Discovered / Source request / Manual (maps added_by) |

## For-review file (conditional)

Only when the finalize-time pending-review write failed: the approved-discovery
rows in pending-review column order. The hand-over says, in one line: "Paste these
rows into [pending_review.file_name]. I couldn't write it this run."

## Format

A header row, then one row per reporter; no blank rows, so the list sorts and
filters cleanly. Score with two decimals. Reactive rows sort first in their
segment and carry their deadline; flags and "verify contact" notes stay in
their columns.
