# AI-cited outlets

Outlets that demonstrably earn citations in AI answer engines (ChatGPT,
Perplexity, Gemini) when users ask about the agency's verticals. Reporters at
these outlets get a bump WITHIN the outlet-fit scoring dimension — AI engines
cite trusted editorial coverage, not wire distribution.

Manually maintained. Refresh quarterly: ask each engine 5–10 questions a real
buyer in the vertical would ask, and record which outlets get cited.

**This is the shape only. The agency's list lives at
`<memory>/media/ai-cited-outlets.md`, because a plugin's own folder can't be
written once uploaded. Until that file exists, outlet_fit scores normally and no
bump applies (the skill notes this once per run, quietly).**
